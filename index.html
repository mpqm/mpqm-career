자기소개

"새로운 것을 경험하고 성장하는 사람"

  안녕하십니까. 2023년부터 Node.js와 Spring Boot를 기반으로 성장하고 있는 주니어 백엔드 개발자 박종성입니다.
저는 정보보호학과에서 CS 및 보안 분야를 깊이 있게 공부해왔습니다. 학부 시절, 파이썬으로 구현한 머신러닝 기반 악성코드 분석, 자동차 통신 패킷인 CAN 트래픽 분석 등의 팀 단위 프로젝트를 수행하며 프로그래밍에 대한 이해를 넓혔습니다. 3학년 때는 3개월간 프라이빗 블록체인인 Hyperledger Fabric 교육을 받았으며, 이를 바탕으로 4학년 졸업 작품으로 분산 신원 인증(DID) 기술을 적용한 3세대 신원 인증 서비스 개발 프로젝트를 수행했습니다. 이 프로젝트에서는 중앙화된 방식에서 벗어나 사용자에게 새로운 인증 방식을 제공하는 방법을 모색하고 구현했습니다. 이 과정에서 Node.js 백엔드, React 프론트엔드, Hyperledger Fabric 저장소를 이용해 구현하며, 서비스 개발 역량을 키울 수 있었습니다.
졸업 후에는 한화시스템 BEYOND SW CAMP 과정에서 웹 서비스 개발 프로젝트를 진행하며 부족했던 CICD 개념과 멀티 서버 환경에서의 기술적 문제를 해결하며, 문제 해결 능력을 지속적으로 강화해 왔습니다. 수료 이후 계속해서 개인적으로 학습한 내용을 블로그에 정리하며 지식을 확장해 나가고 있습니다.


"개선을 위해 노력하고 즐기는 개발자"

 팀 프로젝트를 진행하면서 코드에 대한 고민과 개선 방법에 대해 여러 고민을 많이 하게 되었습니다.
N+1이나 조회 개선 적용을 위해 DB 단과 서버단에서의 성능 최적화 방법은 어떤 방식이 최선일까?
대량의 트래픽을 임의로 발생 가정 시, 데이터에 이용한 동시성 제어 방법은 무엇인가?
MSA 환경으로 분리된 서버와 DB에서 통신 시 발생하는 데이터 정합성 문제는 어떻게 해결할 것인가?
스스로 끊임없이 질문을 던지며 개발하는 것을 즐깁니다. 때로는 개선이 잘 안될 수도 있습니다. 하지만 이것에 좌절하지 않고 끊임없이 방법을 찾습니다.


"새로운 기술과 도전"

 이제 저는 저의 경험을 넘어 실제 기업환경에서 고객에게 제공하는 비즈니스 로직은 어떻게 구성되고 동작하는지에 관심이 많습니다.
과부하 환경에서 사용자들이 겪는 불편함을 어떤 방식으로 극복할 수 있는지 궁금하고, 이에 따른 성능 최적화나 테스트 방식 등을 경험해 보고 싶습니다.
저의 다양한 경험과 학습은 현업에서 발생하는 실제 문제를 해결하는 과정에서 기존 기술에 대한 성능 및 새로운 기술의 타당성 분석을 통해,
새로운 기술을 안전하게 도입하고, 기존 기술에 최적화를 적용해 안전하고 빠른 서비스를 개발하는 백엔드 개발자로 지속적으로 발전하고 성장하겠습니다.

기술스택

Frontend Framework

자바스크립트 및 타입 스크립트로 캐러셀, 페이지 네이션, 모달 창 등 화면 기능을 구현할 수 있고, Pinia와 Redux 등 상태 관리 기술을 사용해 백엔드 데이터를 불러올 수 있습니다.

Backend Framework

Java 언어 기반 Spring Boot 서버를 개발하고, Spring Jpa를 통해 데이터 처리 및 Spring Security를 이용해 인증/인가를 구현하고, Kafka와 OpenFeign을 이용해 분리된 서버 간의 동기/비동기 통신을 구현할 수 있습니다. 타입 스크립트 기반 Express 서버를 개발하고, mongoose를 통해 데이터 처리 및 passport를 이용해 인증/인가를 구현할 수 있습니다.

DataBase

관계형 데이터베이스인 MariaDB를 이용해 테이블을 작성할 수 있습니다. 비관계형 데이터베이스인 MongoDB를 이용해 비정형 데이터를 처리할 수 있습니다.

CICD

npm과 gradle을 이용해 빌드하고 이를 Docker Image로 만들어 젠킨스를 통해 프론트엔드와 백엔드 파이프라인을 구축해 쿠버네티스 환경에 배포할 수 있습니다. AWS EC2와 RDS를 이용해 도메인과 Nginx ssl 설정으로 https 통신을 지원하는 서비스를 배포할 수 있습니다.

Tools

VisualStudioCode는 클라이언트 개발과 express 서버 개발에 사용하고, IntelliJ는 스프링 부트 서버 개발에 사용합니다.

Collaborations

프로젝트를 진행 계획과 작성한 API 문서 등은 Notion으로, 온라인 환경에서 회의 시에는 Discord를 사용합니다. 팀 프로젝트를 하면서 여러명이서 작업할 수 있는 환경을 구축할 수 있으며 팀원들과의 작업 병합 시 나타나는 충돌 문제를 해결해왔습니다.

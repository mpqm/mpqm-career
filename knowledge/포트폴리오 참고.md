# MPQM 포트폴리오 참고

## 역할과 범위

`98. mpqm`은 이력서·포트폴리오 웹 프로젝트다. 회사 프로젝트와 별도로 개인 지원 자료의 구성 및 출판 흐름을 참고할 수 있다.

## 재조사에서 확인한 근거

- 로컬 전체 Ref에는 작성자 `mpqm` 커밋 2건이 있다. 2026-11-02자 `29ce509`에서 정적 이력서 HTML, 이미지 자산, GitHub Actions 워크플로가 추가됐다.
- `portfolio-v2/`는 조사 시점 Git 미추적 작업물이다. 한 데이터 파일을 쓰는 이력서·프로젝트 상세·슬라이드 구성, 이력서 2쪽과 슬라이드 23쪽 검토 PDF가 로컬에 있다. 작성 범위와 실배포 여부는 별도 확인이 필요하다.

## 지원서 제작 활용

- 산출물별 문장 길이와 프로젝트 배치는 기존 검토본을 참고하고, 최신 역할·수치·측정 조건은 [통합 지원 자료](%EC%A7%80%EC%9B%90%20%EC%9E%90%EB%A3%8C.md)와 프로젝트별 근거에서 가져온다.
- MPQM 웹·PDF 검토본의 구성과 생성 방법은 [포트폴리오 검토본 안내](../carrer/README.md)에 있다. 문구를 갱신할 때는 [대시보드](지원%20자료.md#dashboard), [경력기술서](지원%20자료.md#career), [이력서](지원%20자료.md#resume) 구역을 확인한다. 생성본은 [이력서 PDF](이력서.pdf)와 [포트폴리오 PDF](포트폴리오.pdf)에서 연다.

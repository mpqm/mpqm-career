`carrer/index.html`은 웹 진입점이다. 화면 HTML은 `carrer/templates/`, CSS와 JavaScript 및 생성 도구는 `carrer/static/`에 있다. 경력 DB 관리 방식은 [AGENTS.MD](knowledge/AGENTS.MD), 문서 변경은 [HISTORY.md](knowledge/HISTORY.md)에서 확인한다. 경력 문서의 회사 프로젝트 원본 경로는 OneDrive 작업공간 기준이다.

## 공개 배포 전 확인

GitHub Pages 워크플로는 `main` 푸시 시 `carrer/`를 업로드한다. 공개 Git 원격을 사용할 경우 업무 티켓과 상세 근거가 담긴 `knowledge/`는 첫 커밋부터 추적 대상에서 제외한다. Git 저장소 공개 범위와 Pages 배포 범위를 각각 확인한다.
